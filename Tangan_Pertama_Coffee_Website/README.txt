TANGAN PERTAMA COFFEE
Website tugas Web Application Design

ISI WEBSITE
1. index.html    = Home
2. about.html    = About/Profil
3. products.html = Produk
4. style.css     = desain dan responsive layout
5. script.js     = tahun otomatis di footer

CARA MENJALANKAN
- Ekstrak file ZIP.
- Buka foldernya di VS Code.
- Klik kanan index.html lalu pilih "Open with Live Server" jika extension Live Server sudah terpasang.
- Atau klik dua kali index.html untuk membukanya langsung di browser.

UNTUK MENDAPATKAN LINK
Website ini berupa website statis. Untuk dikumpulkan sebagai link, folder ini bisa di-upload ke GitHub Pages, Netlify, atau layanan hosting statis lainnya.

CATATAN
Nama brand, harga, dan isi produk adalah contoh untuk tugas dan masih bisa kamu ubah.
